Для добавления новой функции в Wendy вам нужно:
1) Написать что вы хотите добавить в Wendy на любом языке, будь то C/C++, C#, Java, Python или bash.
2) Добавить ваш модуль в папку Modules.
3) Добавить в "Dictionary.txt" слово-активатор по следующему  примеру:
    слово-активатор=название модуля, который вы добавили.

    Реальный пример:
    офис=office.java
