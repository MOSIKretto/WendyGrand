Старт:
Для старта WendyGrand откройте в терминале папку с Wendy и запустите командой 
./Start.sh она сама соберет необходимые библиотеки и откомпилирует нужные модули. 


Команды основного кода:
1) (Отклик):
Венди + "привет", "здравствуй", "ты тут" или просто "Венди"

2) (Прекращение работы):
Венди + "пока", "закройся"

3) (Браузер (только firefox на данный момент))
Венди + "браузер", "интернет"

4) (Телеграм):
Венди + "телеграм", "телега", "телегу"

5) (Obsidian):
Венди + "обсидиан"

6) (VScode):
Венди + "код", "VScode"

7) (Магазин приложений (только pamac-manager на данный момент)):
Венди + "магазин", "стор"

8) (Перезапуск):
Венди + "перезапуск", "перезапусти компьютер"

9) (Выключение):
Венди + "выключение", "выключение компьютера", "выключи компьютер", "выключить компьютер", "занавес"

10) (Спящий режим):
Венди + "спящий режим", "спать", "антракт"

11) (Обновление системы(apt, dnf, yum, pacman)):
Венди + "обнови систему", "обновить систему"

12) (Офис):
Венди + офис

13) (Пасхалка):
Венди + создатель
