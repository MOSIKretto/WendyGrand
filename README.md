## 🚀 Краткий обзор

WendyGrand — это мощный голосовой помощник с открытым исходным кодом, разработанный для полного контроля над вашим компьютером с помощью голосовых команд. Благодаря модульной архитектуре и гибкой системе конфигурации, Wendy может выполнять абсолютно любые задачи — от запуска приложений до сложных автоматизированных сценариев.

## ✨ Особенности

### 🎯 **Ключевые возможности**
- **🎤 Офлайн распознавание речи** — использует VOSK для работы без интернета
- **⚡ Мгновенный отклик** — минимальная задержка между командой и выполнением
- **🔧 Полная настраиваемость** — гибкая система конфигурации под ваши нужды
- **🧩 Модульная архитектура** — легко расширяемый функционал
- **🔄 Автоматизация всего** — от простых команд до сложных рабочих процессов

### 🛡️ **Преимущества**
- **Конфиденциальность** — все данные обрабатываются локально
- **Стабильность** — написан на Java, работает везде
- **Бесплатность** — полностью open-source под лицензией GPLv3
- **Сообщество** — активная разработка и поддержка

## 📦 Быстрый старт

### Требования
- **Java 24** или новее
- **Микрофон** (встроенный или внешний)
- **~500 МБ** свободного места на диске

### Установка
1. **Скачайте последнюю версию** с [страницы релизов](https://github.com/MOSIKretto/WendyGrand/releases)
2. **Распакуйте архив** в удобную директорию
3. **Запустите** `WendyGrand.jar`
4. **Настройте** голосовые команды под свои задачи

## ⚙️ Настройка

### 📝 Структура конфигурационного файла
Конфигурация Wendy построена на простом и понятном синтаксисе:

```ini
# Удаление слов-паразитов из распознанной речи
delete = ну, это, типа, как бы, э-э-э

# Общие фразы для озвучки (переменные)
$commonVoice = OneMoment, Doing, Done, AlwaysAPleasure

# Команды и их активаторы
kitty, code(1), Telegram(2) = протокол работа = $commonVoice
```

### 🔤 Синтаксис команд
```
<действия> = <фразы-активаторы> = <файлы-озвучки>
```

**Элементы команды:**
- **Действия** — приложения, скрипты, модули
  - `программа` — запуск без задержки
  - `программа(2)` — запуск с задержкой 2 секунды
- **Активаторы** — фразы для активации команды
- **Озвучка** — звуковые файлы для ответа

### 🎨 Примеры конфигурации

```ini
# Базовые команды
notepad = открой блокнот, запусти блокнот = OpenNotepad
chrome = открой браузер, запусти хром = OpenBrowser

# Комплексные команды
photoshop(1), lightroom(3) = настройка фото = ProcessingPhoto
shutdown = выключи компьютер, завершение работы = ShutdownConfirm

# Использование переменных
$workApps = code, telegram, figma
$workVoices = StartWorking, AllSet, DoneForToday

$workApps = поработаем, время работы = $workVoices
```

## 🧩 Модули

Wendy поддерживает создание собственных модулей для расширения функциональности. Модули могут:
- Добавлять новые команды
- Взаимодействовать с системными API
- Интегрироваться со сторонними сервисами
- Выполнять сложные сценарии автоматизации

### ❓ Часто задаваемые вопросы
**Q:** Wendy работает без интернета?
**A:** Да, полностью офлайн благодаря VOSK.

**Q:** Какие ОС поддерживаются?  
**A:** Windows, Linux, macOS — везде, где работает Java.

**Q:** Можно ли добавлять свои голосовые ответы?  
**A:** Да, просто поместите аудиофайлы в папку `voices/`.
